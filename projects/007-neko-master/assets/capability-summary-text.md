# 从连接记录到流量历史

能看什么：总量与趋势、设备来源、域名 / IP、规则 / 代理链、国家 / ASN、多网关。

直连 Clash/Mihomo 通过 WebSocket 到中心采集器；直连 Surge 通过 HTTP 轮询到中心。远程 Clash/Surge 在该提交 Go Agent 中通过 HTTP 轮询获取，由 Agent 计算增量并 HTTP 上报。

核心：当前累计字节减上次累计字节；初见计当前累计，回退走重置分支。新增量同时进入实时内存与批量缓冲，批量写入 SQLite / 可选 ClickHouse；查询合并历史与未落盘增量，再经 API / WebSocket 展示。

目标 IP 补充国家与 ASN，网关元数据提供规则与策略组选择。边界：只分析网关可见数据；策略链不是逐跳路由；没有 HTTPS 解密；重启、采样和队列溢出可能影响完整性。上游图与教学示例均不代表本研究的真实网关测量。
