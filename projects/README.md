# 研究项目

子项目统一使用 `NNN-slug` 命名，例如 `001-example-repo`。三个数字是最小宽度，超过 999 后继续增长；展示时按数字排序。

使用根目录的新增命令创建项目，不把模板当作实际研究项目。已归档项目保留编号与目录，避免旧链接失效。

每个项目包含：

- `project.json`：名称、编号、摘要、上游仓库、状态、演示链接、封面信息。
- `README.md`：研究概览、环境与运行步骤、阶段结论和图片展示。
- `notes.md`：源码阅读与实验过程记录。
- `assets/`：封面和截图。
- `web/`：可选的演示源码目录，确定技术栈时再添加。

完整列表见[首页索引](../README.md#项目索引)。
