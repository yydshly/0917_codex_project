# Agency Agents 总览图生成说明

- 最终方式：HTML/CSS 精确排版，经 Chromium 按 2 倍分辨率导出 PNG（2880 × 4884）。
- ImageGen 尝试因网络错误失败，未产出可用图片；没有使用 CLI/API 备用生成路径。最终内容以可编辑排版源码为准。
- 最终排版源码：`../web/capability-summary.html`；成品：`capability-summary.png`。
- 用途：研究信息图；不是上游角色运行结果或性能证据。
- 数据来源：`web/catalog.json`，基准 commit `ad9264e309bd5e5422c04784372d7841b1e5d604`。
- 角色选择依据：按本仓库研究流程初选，未做角色效果对照实验。
- 状态：实际效果和核心增量价值留待后续深度测试。

## 最终内容规范

1. 定位：按领域、按身份定制的 skill 提示词库。
2. 范围：18 个领域、279 个角色；数量不代表质量。
3. 候选：按本仓库研究需求初选六个角色，列明用途与选择原因。
4. 模型影响：真实效果与模型能力有关；模型提升可能改变增量价值。
5. 对我们的意义：后续根据实际需要验证相关身份和能力，不预设有效。
6. 验证：同一模型、同一批任务，对比直接给任务、上游角色与精简规范。
