# 场景迁移记录

## 为什么选升降椅

它能用少量清晰规则展示一套完整的产品交互：条件控制（抬杆）、输入条件（承重）、状态变化（高度）、边界（行程）、锁定（后仰）和装配联动。与自行车相比，机构更易理解，适合解释通用展示能力与对象专属规则的区别。

## 可以复用与需要重写的部分

可复用的方法：React 配置状态、Three.js 场景循环、相机特写、射线拾取、父子节点、材质切换、分解视图、静态构建与移动端布局。

重新编写：椅子几何、气杆高度规则、后仰同步关系、扶手和腰托结构、五星脚与脚轮。没有复制自行车链条或制动模型来冒充椅子机构。

## 状态如何流动

用户选择承重、拨杆或后仰角度 → React 更新配置 → 每帧调用 advanceChair → 计算当前高度、后仰、旋转与锁定 → Three.js 更新节点 → 大约每 80 ms 检查一次，仅在显示读数或状态变化时回传界面。三维渲染循环仍然持续运行，尚未改为静止时按需渲染。

自动演示为四个 5 秒阶段。启动必须由用户操作，默认模型静止；停止后关闭演示拨杆并保留当前高度，其他角度恢复用户手动配置。

## 可用于下次的提示词

制作一个可交互的三维升降椅演示，包含五星底座、脚轮、伸缩气杆、座下拨杆、坐垫、靠背、扶手、腰托和头枕。抬杆且空载时升高，抬杆且承重时降低，松杆保持高度；设置明确行程限制。靠背可以调角度并锁定，配件随所属装配移动。提供材质切换、部件特写、分解、重置和主动启动的自动演示。将界面、三维几何与运动规则分开，明确这是教学运动示意；实际验证极限参数、锁定、暂停和手机端布局。
