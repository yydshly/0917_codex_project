# 升降椅演示约定

- 本项目从 010 自行车演示的交互方式迁移，保持独立 React + Three.js 应用，不修改自行车子项目。
- 界面面向非技术用户，中文优先；升降、后仰锁定及配件的操作要有可观察的三维反馈。
- 气杆为教学运动示意：抬杆且空载时升高，抬杆且承重时降低；松杆保持高度，不能假称气压仿真。
- 自动演示由用户主动启动；停止、恢复默认和参数边界必须工作。
- 截图使用真实浏览器渲染，放在项目 assets/，完成时更新中文说明和项目索引。
- 静态输出为 site/apps/012-lift-chair-studio/，不默认公网部署。

- 用户指出升降椅质感明显弱于自行车。后续需以三维产品质感作为验收项，优先软包曲面、真实尺度纹理、材质区分、制造细节及光照层次，不能只验证操作能否工作。
