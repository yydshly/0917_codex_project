## 定位与能力

这是原版 Agency Agents 的中文社区衍生版。角色源文件以 Markdown 定义身份、规则、执行流程和交付要求；安装与转换脚本将内容组织成不同 AI 工具所需的格式。

本次扫描实际文件，得到 **277 个角色、20 个部门**。完整清单及固定版本源链接保存在 [web/catalog.json](web/catalog.json)，网页支持按角色中文名、英文路径搜索和按部门筛选。仅统计具有 frontmatter 和单行 `name` 的角色 Markdown，策略文档、示例和集成产物不计入角色数。

主要内容增量：

- 中文化：翻译原版角色的工作步骤、规则与交付要求，方便我们阅读和改写。
- 本地化与原创：调整国内业务场景，并增加公司经营、国内平台和部分行业角色。
- 工具适配：通过脚本转换和安装角色配置；适配声明不等于兼容性与效果均已实测。

## 与原版的差异

| 维度 | 原版 001 | 中文版 002 |
| --- | --- | --- |
| 核心机制 | 角色提示词、工作步骤与交付标准 | 同类机制，增加翻译、本地化和原创内容 |
| 文件统计 | 279 个角色、18 类 | 277 个角色、20 类；分类方式不同 |
| 语言 | 角色内容以英文为主 | 中文更便于我们的理解、审阅与改写 |
| 中国场景 | 已有小红书、微信、抖音、飞书等角色 | 更强调中国业务场景，但这些方向并非全部独有 |
| 更新关系 | 原版独立演进 | 翻译同步与原创扩展并行，不能直接当作当前原版的完整超集 |
| 协作执行 | 编排角色与流程文本 | 也有编排角色，另推荐独立软件 Agency Orchestrator |

作者标为“原创”的角色不一定是当前原版没有的角色。网页讨论的是定位与内容范围，未逐段审阅所有角色的翻译质量，也未独立核实所有原创归属。

`agency-orchestrator` 是另一个执行软件项目。其模型接入、并行任务、断点续跑和图形界面不能计为这个角色库本身已经提供并运行的功能。本次只核对项目关系，未安装或运行该软件。

## 对我们的价值

当前价值是建立便于查阅和改写的中文角色候选库。研究 GitHub 项目时，可以按需参考代码库导读、技术写作、证据收集与核验方法；遇到飞书、钉钉或工业项目，再选取相应领域的角色内容。

不因角色数量或中文语言直接认定效果更好，不要求全量安装，也不替换已经有效的研究方法。我们此前筛选的六个原版角色继续作为候选；中文快照中未检出 Research Synthesist 同名或同路径角色，不据此断言没有相近方法。

下一步可在同一项目、同一模型和相同工具条件下，比较现有研究要求、原版精选角色、中文版对应角色。记录事实错误、证据追溯、复现成功率、耗时和返工次数，再判断实际增益。模型升级后重新评估。

## 能力边界与证据

角色指令不直接提供基础模型能力、账号权限、平台连接器、持久化记忆或自动执行调度器。角色中的专业规则和技术示例仍需结合官方资料与真实环境核对。

已核查版本、许可证、目录、角色文件及重点内容；尚未安装角色、测试跨工具兼容性、验证多角色运行效果或进行效率对照。网页截图仅证明研究页面的展示状态。

上游首页规模表与角色清单标称 213 个翻译和 64 个原创，但部分正文仍保留 63 个原创、268 位在线专家等旧数字；UPSTREAM.md 仍记录六月的 266 个。实际文件统计为 277，网页采用此数。来源分类仍按作者声明理解。

## 网页与复现

```powershell
python scripts/projects.py sync
python scripts/projects.py check
python scripts/build_site.py
python -m http.server 8766 --bind 127.0.0.1 --directory site
```

访问 http://127.0.0.1:8766/apps/002-agency-agents-zh/ 。普通构建使用已保存的角色快照，仅依赖 Python 标准库，无需联网或上游副本。资源与页面链接使用相对路径，可部署在 GitHub Pages 项目子路径下，也可直接打开静态 HTML。

只有主动更新研究版本时，才运行快照提取脚本并重新审阅内容，见 [web/README.md](web/README.md)。本次完成本地网页与站点接入，尚未发布本项目的新版本；`demo` 留空，避免把计划地址写成已验证的公开地址。
