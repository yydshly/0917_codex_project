# 细节模块分析与第二轮优化

最新进展：[刹车与滑行](braking-and-coasting.md)已补独立前后刹和简化惯性模型；下表为第二轮的历史记录。

后续排查见 [第三轮细节排查与优化](regression-review.md)：补充转向轴、分解检视跟随、卡钳装配归属、轮框连接点、隐藏部件点选与手机检视修复。当前回归测试共 12 项。

本轮反馈：链条等细节不足，需要优化并分析模块。第一版完成了功能入口，但传动结构主要是外形示意；本轮以近景中能辨识结构、运动链路完整、操作可验证为验收标准。

## 模块对照

| 模块 | 第一版的不足 | 本轮实现 | 仍有的边界 |
| --- | --- | --- | --- |
| 链条结构 | 100 个小方块，链片、滚子、销轴无法分辨 | 118 节闭合链路；交替内外链片、两侧金属板、滚子、贯穿销轴与橙色追踪链节 | 链片沿圆弧采用弦长缩放，未解刚体接触约束 |
| 链条走向 | 平滑样条连接牙盘和飞轮，未经过后拨 | 牙盘 → 下张紧轮 → 上导轮 → 飞轮，直线公切线 + 圆弧包覆组成闭环 | 没有链条弹性、松边振动和跳链模拟 |
| 链长与节距 | 固定实例数量，与节距无明确关系 | 名义节距 12.7 mm；微调张紧轮位置，使整圈为偶数个节距，当前 118 节 / 1.4986 m | 模型的 12.7 mm 是沿路径间隔，圆弧上的销轴弦距有近似；不作生产数据 |
| 牙盘与曲柄 | 圆环 + 小方块齿，简单直杆脚踏 | 54 / 40 齿两片牙盘、齿形轮廓、五臂支架、五颗安装螺栓、曲柄中心螺栓与脚踏轴 | 固定使用大盘，不支持前拨换盘或制造级齿形 |
| 飞轮 | 八个光滑圆环，不随链路正确展示细节 | 12 片带齿飞轮，11/12/13/14/15/16/17/19/21/24/28/32T；16T 为工作档，含支撑臂和锁环 | 未实现切档与横向链线变化 |
| 后拨 | 一根弯曲杆，没有上下导轮 | 固定连杆、两侧导板、固定螺栓、两个 11T 导轮；上、下导轮根据链条方向反向旋转 | 连杆机构用于外形讲解，不含真实平行四边形换档运动和弹簧力 |
| 运动关系 | 曲柄转、车轮转，链条不够清楚 | 曲柄、链条、飞轮、双导轮、前后轮由同一运动增量驱动；脚踏平台保持水平 | 仍是固定齿比运动学，没有飞轮棘轮滑行、踏板载荷和受力求解 |
| 轮组细节 | 简单轮毂与辐条 | 补两侧轮毂法兰、气嘴与辐条帽，保留轮框深度切换 | 未建轮胎真实胎纹、编轮张力与胎体变形 |
| 制动 | 一个圆环加六根辐射杆 | 打孔碟片、六臂支架、固定于车架 / 前叉的卡钳和固定件；碟片随轮转，卡钳不随转 | 没有液压、摩擦、温升和制动力计算 |
| 车架 / 操控 / 坐垫 | 管件、弯把和软垫形体较简化 | 保留现有 PBR 配置和转向，修正光照强度以便观察金属结构 | 后续可补车架截面、碳布纹理、把带缠绕、坐垫开孔；本轮未伪称全部达到精细 CAD |
| 检视能力 | 单一传动视角，链条太小；细看会遮挡 | 新增链条特写、牙盘曲柄、飞轮后拨、总览四个观察位置，传动独显、0.15× 慢动作、单齿步进及状态提示 | 不等同于精确 CAD 测量或零件编辑 |

## 拆分后的实现

- `web/src/mechanics.js`：纯运动与路径模块。统一节距、齿数、节圆半径、圆的有向公切线和闭合路径采样。
- `web/src/drivetrain.js`：独立传动装配。构建链片 / 滚子 / 销轴实例、牙盘、飞轮与后拨，并消费统一运动增量。
- `web/src/scene.js`：整车装配、相机、灯光、轮组与制动；负责将输入状态分发给传动和车轮。
- `web/src/App.jsx`：用户检视操作和反馈；离开传动独显时恢复整车，单步时暂停连续播放。
- `web/src/config.js`：中文部件规格与配置数据；慢动作只改变动画播放倍率，踏频等物理输入不随之变小。

### 同步关系

一次单齿步进对应：链条前进 12.7 mm、54T 牙盘转 1/54 圈、16T 飞轮和车轮转 1/16 圈、11T 导轮转 1/11 圈。导轮转向由绕行方向决定。普通播放和慢动作使用同一套增量，暂停后没有时间漂移。

当前链长为 1.4986 m，118 个名义节距。张紧轮位置通过二分微调，使路径闭合处没有一节特别短的接缝。与真实链条的多边形啮合不同，圆弧段仍使用连续路径采样，链片显示长度随弦长略变；目前只提供可观察的运动学近似，不宣称销轴刚距或齿面接触精度。

## 操作方法

1. 点击顶栏 **传动**，右侧自动打开部件规格与传动检视。
2. 选择 **链条特写 / 牙盘与曲柄 / 飞轮与后拨 / 传动总览**。
3. 开启 **传动独显**，排除车架和轮组遮挡。
4. 开启 **0.15× 慢动作**观察运动，或点击 **单步推进 1 齿**逐次检查。单步会暂停连续播放，底部播放按钮可继续。
5. 点击其他部件或离开传动配置，独显自动恢复；全局重置清除步进、慢动作与独显。

## 实测与修复

- 新增路径闭合、段连接连续、公切线、偶数节距、单步齿比和慢动作同步测试，连同原配置测试共 7 项通过。
- 浏览器测试中两次单步显示“已步进 2 齿”，动画暂停；离开独显后，再次进入时该状态为 false。
- 手机 390 × 844 验证发现隐藏热点仍撑宽页面，已为场景加裁切边界。修复后 `scrollWidth = 375`、`innerWidth = 390`（包含纵向滚动条），不再横向溢出。
- 调整窄屏传动取景后，整套牙盘—飞轮—双导轮链路可完整看见。
- 优化后浏览器控制台未见 error / warn；静态构建仍有单包体积提示，属于加载体积提醒。
