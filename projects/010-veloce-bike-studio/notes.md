# 研究与验证记录

日期：2026-09-17。

1. 原站展示页含约 82 万字符打包 JS，没有公开代码仓库或 Source Map。保留截图与交互证据，没有导入原站应用代码。
2. 新建 010 子项目；使用 React 19 + Three.js 0.180 + Vite 6，独立制作场景与 UI。
3. 验证 5 种涂装、3 种轮组、3 种接触点配色、五类部件、五个视角、热点、气流、自动旋转和三个运动滑块。
4. 深框轮组显示 6.80 kg / 24.8 W；轻量轮组显示 6.53 kg；默认 78 RPM 对应约 33.7 km/h。暂停或零踏频时速度和估算功率为零。
5. 第一轮发现车型偏小、低高度桌面左栏被底部控制遮挡、分解坐垫裁切。已调整整车取景、侧栏滚动 / 紧凑布局和分解取景；最终证据见 design-qa.md。
6. 移动端 390 × 844 检查：整车可见；页面实际宽度 390 px，无横向溢出；轮组切换和面板收起正常。
7. 单元测试覆盖重量差、传动换算、暂停 / 零踏频及项目来源元数据兼容性。浏览器验证作为场景行为证据，不能以单元测试代替视觉验证。

进一步工作：制造级几何、真实材料贴图、配置导出以及接入经验证的计算模型均不在本次复刻范围内。
