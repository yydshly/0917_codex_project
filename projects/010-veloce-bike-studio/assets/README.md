# 项目图片

将真实封面、界面截图和架构图保存在这里，建议使用简短英文文件名。

推荐封面为 `cover.png` 或 `cover.webp`。在 `project.json` 中填写相对于子项目目录的 `cover`（例如 `assets/cover.png`）以及描述图片内容的 `cover_alt`，然后在仓库根目录执行 `python scripts/projects.py sync`。

文档中的图片使用相对路径，并配合说明、截图时间、对应版本和素材来源。没有截图时保持封面字段为空。
