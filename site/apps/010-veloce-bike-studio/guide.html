自行车：机械结构与联动的 3D 实现参考

机械产品的 3D 实现参考：用 React + Three.js 展示材质配置、传动与制动联动、配件装配和部件检视，供产品配置器与结构教学复用。

从整车展示到链条、制动和配件联动，观察一个可配置产品如何在浏览器中被搭建、操作和检视。可作为后续机械产品展示的实现样本。

这个参考能帮你实现什么

产品配置

涂装、轮组和接触点配色即时反馈，展示几何与材质如何跟随配置变化。

机构联动

传动、换档、前后刹与滑行、转向、灯具、座管快拆，把规则映射到可见零件。

结构讲解

整车与局部机位、部件拾取、热点和分解视图，组织从整体到细节的探索。

建议按这个顺序体验

  1. 先切换涂装、轮组，观察反射和轮廓变化。
  2. 选择传动特写，调整踏频与档位，观察牙盘、链条、飞轮和后拨。
  3. 进入刹车与滑行，区分停止踩踏、制动与暂停模拟。
  4. 查看手机支架、水壶、灯具和座管卡扣，观察配件与所属装配的联动。
  5. 展开部件分解，再恢复整车，比较结构关系。

React、Three.js 和我们自己写的代码

核心是通用网页与三维能力，具体产品行为由项目代码实现。这里不是一个安装后就自带全部功能的“自行车库”或“椅子库”。

层次提供的能力当前实现
React界面与状态按钮、滑杆、页签、选中项、配色与读数。
Three.js三维渲染与交互几何、材质、灯光、阴影、相机、点击拾取与动画循环。
自定义 JavaScript对象专属规则固定销距链条、变速路径、车轮与曲柄状态、制动减速、配件随车把或座管运动。
Vite构建与交付打包成本地资源，部署到 GitHub Pages 子路径，无应用后端。

操作 → 更新配置 → 计算运动状态 → 更新三维节点 → 回传界面读数。可复用的是这条流程；几何造型、装配层级和运动约束需要按对象重写。

为什么自行车容易做精细，人物更难

车管、轮圈和紧固件接近规则几何体，适合程序化搭建，再通过金属、车漆和橡胶的不同反光表现结构。椅子软包需要连续曲面、织纹和缝线；人体还需要准确比例、连续关节、衣物形变及自然动作。

当前人物由简化几何生成，保持固定坐姿，尚未使用带骨骼的精细人物。提高灯光或分辨率不能替代模型质量。下一阶段应先改善人物模型与接触姿态，再加入蹬地、收脚和受压反馈；同一套 React + Three.js 可以继续承载这些资源。

下次如何提出类似需求

说明对象、部件、规则、视觉标准和验收方式，比只说“做一个炫酷 3D 页面”更明确。

制作一个可交互的三维机械产品演示。明确列出车架、轮组、传动、制动和配件；提供材质配置、部件特写、拾取、分解和重置。先定义部件的父子关系，再定义踏频、换档、制动、暂停和快拆锁定的规则。采用有层次的金属、橡胶与车漆材质，近景要能看清连接件。区分教学估算与真实仿真；实际验证极限参数、运动联动、暂停恢复、桌面和手机布局。将界面、建模和运动规则拆分为独立模块。

适用场景与边界

适合机械产品配置器、结构教学、配件组合展示、交互原型与 Three.js 实现学习；可迁移到工具、家电、运动器材等对象。

  • 参考网页未提供已确认的公开源码库；此项目是独立实现，不冒充原站源码或原站授权。
  • 功率、重量、气动与制动为演示估算或教学模型，未进行 CFD、刚体碰撞或结构强度求解。
  • 主要模型由代码构建；没有加载厂商 CAD，演示参数不是实测产品数据。
