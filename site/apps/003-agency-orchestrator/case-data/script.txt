## 完整提示词（可直接复制）

```
你是一位会议纪要整理专家。请根据以下混乱的会议记录，提取并整理为结构化的待办表格。

要求：
1. 每一条提取：任务、负责人、截止时间
2. 记录中未明确写出的字段，填写「待确认」，不推断、不猜测
3. 如果同一任务有多人负责或存在冲突，保留原样并注明「需人工确认」，不擅自选第一个
4. 只输出表格，不附加说明

以下是会议记录：
[粘贴你的会议记录]
```


## 话术风格自检

| ✅ 检查项 | 对应 |
|-----------|------|
| 前 5 秒有明确冲突钩 | 「两小时 vs 一句话」 |
| 无绝对化用语 | 无「最简单」「100%」「三秒钟」等 |
| 每句话不超过 15 字 | 控制语速，留字幕时间 |
| 结尾有互动引导 | 「评论区告诉我」 |
| 提示词可复制 | 放在评论区 + 视频内大字展示 |
| 无效率承诺 | 已删除「三秒钟」，改为「帮你整理」 |

| 步骤 | 时长 | 操作 |
|------|------|------|
| 1 | 5 分钟 | 打开备忘录，新建文案文档，粘贴口播稿 |

| 4 | 8 分钟 | 导入剪映，添加字幕（自动识别），加关键帧放大「待确认」两处，添加轻BGM（BGM 音量调到 15%） |
| 5 | 2 分钟 | 导出，发布到抖音，标题用「会议开了两小时，只记住一句话——用提示词整理」，评论区置顶提示词 |
| **合计** | **30 分钟** | |
